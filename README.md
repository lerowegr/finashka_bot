# Финашка-бот 2.0

Telegram-бот для абитуриентов: помогает выбрать **направление подготовки, вуз и образовательную программу** по актуальным данным с [tabiturient.ru](https://tabiturient.ru).

Это переработанная версия старого бота, который читал данные из вручную заполняемых Excel-файлов. Новая версия сама собирает данные с сайта в локальную базу и обновляет их по расписанию.

## Ключевой принцип архитектуры

**Бот никогда не ходит на сайт в момент запроса пользователя.** Скрейпер наполняет локальную БД по ночам, бот читает только из неё и отвечает на каждый клик за миллисекунды. Доступность и скорость бота не зависят от сайта-источника.

```
tabiturient.ru ──> Скрейпер ──> ETL ──> SQLite ──> Бот (aiogram)
   (раз в ночь,      httpx +      upsert   локальная    читает только
    вежливо 1 rps)   selectolax   + диффы    БД          из БД
```

Слои разделены так, что домен-сервисы (`app/domain/services`) не знают ни о Telegram, ни о парсере — на них позже можно поднять API для Telegram Mini App без переписывания логики.

## Структура

```
src/app/
├── config.py            # настройки из .env (pydantic-settings)
├── db/                  # ORM-модели и async-движок (SQLAlchemy 2.0, WAL)
├── scraper/             # клиент, парсеры страниц, ETL-конвейер
│   ├── parsers/         #   по модулю на тип страницы сайта
│   └── etl.py           #   fetch -> parse -> validate -> upsert
├── domain/services/     # бизнес-логика: каталог, поиск, вузы, избранное
├── bot/                 # aiogram: хендлеры, клавиатуры, тексты карточек
├── seed.py              # авторские данные из старых Excel (описания и т.п.)
└── cli.py               # команды управления
tests/                   # контрактные тесты парсеров на реальных страницах
```

## Данные

Собираются с сайта: вузы (регион, тип, категория, общежитие, средний балл, факультеты), направления (код, уровень, агрегаты по России), программы (профиль, экзамены ЕГЭ, по каждой форме обучения — проходной балл с динамикой, бюджетные места по квотам, средний балл зачисленных, стоимость).

Берутся из старых Excel (на сайте отсутствуют) и хранятся в `data/seed/`: описания направлений, «кем работать», военные учебные центры.

## Установка и запуск

```bash
python -m venv .venv
.venv/Scripts/activate        # Windows; на Linux/macOS: source .venv/bin/activate
pip install -e ".[dev]"

cp .env.example .env          # и указать BOT_TOKEN
```

Первичное наполнение БД:

```bash
python -m app.cli db-init                # создать схему
python -m app.cli seed-extract           # вытащить авторские данные из старых Excel
python -m app.cli etl light              # обойти вузы и списки программ
python -m app.cli etl np                 # агрегаты направлений
python -m app.cli etl full               # карточки программ (долго; можно позже)
python -m app.cli seed-apply             # наложить описания и военные кафедры
python -m app.cli migrate-favorites      # перенести избранное из старого бота
python -m app.cli stats                  # проверить, что в БД
```

Запуск бота:

```bash
python -m app.bot.main
```

## Обновление данных

`python -m app.cli schedule` запускает планировщик:

- **каждую ночь (03:00)** — лёгкий обход вузов и списков программ + агрегаты направлений (~45 мин): свежие баллы, наборы ЕГЭ, новые программы;
- **раз в неделю (вс, 01:00)** — полные карточки программ со стоимостью и местами (эти данные меняются редко).

Отдельные команды `etl light|np|full` можно запускать вручную. Каждый обход пишет итог в таблицу `scrape_run`, а при настроенном `ADMIN_CHAT_ID` шлёт сводку в Telegram.

## Тесты

```bash
pytest -q
```

Контрактные тесты парсеров прогоняются на сохранённых реальных страницах сайта (`tests/parsers/fixtures/`) — при изменении вёрстки сайта падают тесты, а не продакшн.

## Возможности

**Сейчас (MVP):** каталог по уровню образования (раздел → УГСН → направление), карточка направления со списком вузов и баллами, вузы по регионам, поиск направлений по набору предметов ЕГЭ, избранное (направления, вузы, программы).

**Дальше:** профиль «Мои баллы ЕГЭ» с подсветкой шансов, дни открытых дверей, уведомления об изменениях (баллы, стоимость) на основе диффов обхода, сравнение вузов, Telegram Mini App.
